# 系统总览（后端）

## 这是什么
《在线影评系统》的**后端**（Spring Boot + MySQL），为前端（Vue，队友维护，位于仓库 `movie-review/`）提供 REST API。两类角色：普通用户、管理员。

> **接口契约以仓库根目录 `apiDesigner.md` 为权威**。本架构文档只讲"后端怎么组织实现"，不重复抄接口；字段级细节看 `apiDesigner.md` 与 Swagger。

## 核心业务（大致做什么）
- **注册—审核—登录**：用户注册后 `status=pending`；管理员 `approve/reject`；只有 `approved` 能登录并发评论。JWT 鉴权，区分 `user`/`admin`。
- **影片管理**：管理员增/改/删影片；删除为**软删除**（`deleted=true`，保留评论，前端不展示）。
- **搜索与浏览**：普通用户按关键词模糊搜影片（标题/导演/演员），看详情与评论。
- **评分评论**：approved 用户对影片打分(1-10)+评论；**一人一片一评**（重复 409）；可改/删自己的评论。
- **排行榜**：按影片平均分排序。`averageScore`、`reviewCount` 由后端在**评论变更时实时维护**（冗余字段，保证排行榜一致与性能）。
- **访问日志**：后端用 **AOP/拦截器自动记录**用户关键动作（登录、搜索、看详情、评论、看排行等），管理员可按条件查询。前端无感知。

## 模块划分（功能切片的大致边界）
1. **基础设施**：统一响应 `Result{code,message,data}`、全局异常处理、分页约定、Swagger、Flyway 基线。
2. **认证与用户**：注册、登录、当前用户信息、改资料。
3. **管理员**：待审用户列表、审核、影片增改删、影评管理（查/隐藏）、日志查询。
4. **影片与评论**：影片列表(搜索)、影片详情(含评论分页)、发/改/删评论、排行榜。
5. **访问日志**：AOP 切面自动记录 + 管理员查询。

## 跨切面机制（贯穿各模块）
- **统一响应包装** + **全局异常处理**：把异常转成契约里的 `code/message`（如 401/403/409）。
- **JWT 过滤器**：解析 token、放行公开接口、注入当前用户，做角色与 `approved` 状态校验。
- **AOP 日志切面**：自动记录 `action` 枚举（见 `apiDesigner.md` 第 4 节）。
- **评分冗余维护**：评论增/改/删时，同事务内更新影片 `averageScore`/`reviewCount`。

## 已知"契约留白"（实现到相关处，按"遇事不决"规则——重大决策停下问用户）
- 评论的 `likeCount` 字段在契约响应里出现，但**没有点赞接口**。默认：建字段、默认 0；**是否做点赞 API = 重大决策，停下问用户**。
- 排行榜 `timeRange`（week/month/all）契约标注"若实现"。默认先做 `all`；做时间筛选前问用户。
