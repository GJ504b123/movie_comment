## 做了什么

### AOP 访问日志切面（切片5本体）

| 文件 | 说明 |
|------|------|
| `aspect/LogAction.java` | 自定义注解 `@LogAction(ActionType, targetParamName)`，标在 Controller 方法上 |
| `aspect/AccessLogAspect.java` | `@Around("@annotation(logAction)")` 切面：从 UserContext 取 userId/username，从注解取 action，从参数取 targetId，从 HttpServletRequest 取 IP/UA，方法成功后插 `access_log` |

#### 注解分布（5 个 Controller，11 个方法）

| Controller | 方法 | 注解 |
|---|---|---|
| MovieController | listMovies | `@LogAction(SEARCH_MOVIE)` — 仅 keyword 非空时记录 |
| | getMovieDetail | `@LogAction(VIEW_MOVIE_DETAIL, targetParamName="movieId")` |
| ReviewController | createReview | `@LogAction(POST_REVIEW, targetParamName="movieId")` |
| | updateReview | `@LogAction(UPDATE_REVIEW, targetParamName="reviewId")` |
| | deleteReview | `@LogAction(DELETE_REVIEW, targetParamName="reviewId")` |
| RankingController | rankings | `@LogAction(VIEW_RANKING)` |
| AdminController | auditUser | `@LogAction(AUDIT_USER, targetParamName="userId")` |
| | addMovie | `@LogAction(ADD_MOVIE)` |
| | updateMovie | `@LogAction(EDIT_MOVIE, targetParamName="movieId")` |
| | deleteMovie | `@LogAction(DELETE_MOVIE, targetParamName="movieId")` |
| | setReviewVisibility | `@LogAction(HIDE_REVIEW, targetParamName="reviewId")` |

#### 手动日志（AuthController）
`register` 和 `login` 无 UserContext，直接在方法体内调 `accessLogMapper.insert()`，从返回值取 userId。

## 关键决策与假设
- register/login 不走 AOP（无 UserContext），手动插日志，写在方法最后（成功才记）
- 点赞 toggle 模式：前端记本地状态，后端只管 +1/-1，无需去重表
- 排行榜 `sortBy=reviewCount` 直接用冗余列排序，O(1)
